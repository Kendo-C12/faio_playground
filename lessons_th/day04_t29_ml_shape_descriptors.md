**Shape descriptor (ตัวเลขบรรยายรูปร่าง)** คือ ตัวเลขที่คำนวณจากเส้นขอบของวัตถุหนึ่งชิ้น เพื่อสรุปว่ารูปร่างนั้นหน้าตาเป็นอย่างไร เช่น กลมแค่ไหน ผอมแค่ไหน มีกี่มุม

**Invariant (ค่าที่ไม่เปลี่ยนแม้จะหมุน ย่อ ขยาย หรือเลื่อนภาพ)** คือ คุณสมบัติที่ทำให้ตัวเลขตัวหนึ่งยังบอกค่าเดิม แม้วัตถุจะถูกกระทำอย่างนั้น ตัวอย่างเช่น ถ้าตัวเลขตัวหนึ่งไม่เปลี่ยนเมื่อหมุนภาพ เราเรียกว่ามันไม่แปรตามการหมุน

บท T28 เปลี่ยนภาพให้กลายเป็นรายการของ contour ส่วนบทนี้เปลี่ยน contour แต่ละเส้นให้กลายเป็นตัวเลข บางครั้งตัวเลขเหล่านั้นคือคำตอบ และบางครั้ง เช่นในโจทย์ task 6 มันเป็นเพียงเครื่องมือตรวจสอบที่ไม่ต้องส่งให้ใคร

**ข้อควรเข้าใจก่อนอ่านต่อ** ความไม่แปรเป็นดาบสองคม ถ้าอยากรู้ว่ารูปเป็นวงกลมหรือไม่ การที่ค่าไม่เปลี่ยนตามการหมุนคือข้อดี แต่ถ้าอยากแยกตัวอักษรสองตัวที่ต่างกันเพียงทิศทางการหันหัว การที่ค่าไม่เปลี่ยนตามการหมุนคือหายนะ เพราะมันลบข้อมูลชิ้นเดียวที่ใช้แยกทิ้งไปพอดี

## [concept-first] ทฤษฎีก่อน แล้วดูตัวอย่าง

ตัวเลขทุกตัวด้านล่างคำนวณจาก contour หนึ่งเส้น ซึ่งก็คืออาร์เรย์ของพิกัดที่ `cv2.findContours` คืนมา

- **จำนวนมุม (vertex count)** คือ จำนวนจุดหักของรูปหลายเหลี่ยมที่ใช้แทนเส้นขอบนั้น คำสั่ง `cv2.approxPolyDP(c, eps, True)` แทนที่เส้นขอบด้วยรูปหลายเหลี่ยมที่จุดต่าง ๆ เบี่ยงเบนจากเส้นขอบเดิมไม่เกิน `eps` จุดภาพ ตั้งค่า `eps` เป็น *สัดส่วนของความยาวเส้นรอบรูป* ไม่ใช่เป็นจำนวนจุดภาพตายตัว คือ `eps = 0.02 * cv2.arcLength(c, True)` จากนั้น `len(approx)` จะเท่ากับ 3 สำหรับสามเหลี่ยม เท่ากับ 4 สำหรับสี่เหลี่ยม และมากกว่าหรือเท่ากับ 8 สำหรับวงกลม วิธีตั้งค่าแบบนี้ทำให้ผลไม่ขึ้นกับขนาดของรูป เพราะ `eps` ขยายตามรูปไปด้วย

  ถ้า `eps` เล็กเกินไป วงกลมจะยังเหลือ 40 มุม และสามเหลี่ยมที่มีขอบเบลอจะรายงานว่ามี 5 มุม ถ้า `eps` ใหญ่เกินไป สี่เหลี่ยมจะยุบกลายเป็นสามเหลี่ยม ช่วงที่ใช้งานได้จริงคือ `0.02` ถึง `0.04` และควรตรวจสอบกับรูปที่รู้คำตอบอยู่แล้วก่อนเสมอ

- **Circularity (ความกลม)** คือ ตัวเลขที่บอกว่ารูปนั้นใกล้เคียงวงกลมแค่ไหน

$$
\text{circularity} = \frac{4\pi A}{P^2}
$$

เมื่อ $A$ คือ พื้นที่ของรูป และ $P$ คือ ความยาวเส้นรอบรูป โดยคำนวณจาก `A = cv2.contourArea(c)` และ `P = cv2.arcLength(c, True)`

  วงกลมสมบูรณ์ให้ค่า 1.0 สี่เหลี่ยมจัตุรัสให้ค่าประมาณ 0.785 สามเหลี่ยมด้านเท่าให้ค่าประมาณ 0.605 และรูปที่ยาวเรียวจะมีค่าเข้าใกล้ 0 ค่านี้เป็นตัวเลขเดี่ยวที่ดีที่สุดสำหรับคำถามว่า "กลมหรือไม่กลม" และไม่แปรตามการเลื่อน การหมุน และการย่อขยาย แต่ **ไม่** ทนต่อขอบที่หยักเป็นฟันเลื่อย เพราะสัญญาณรบกวนทำให้ $P$ ยาวขึ้นในขณะที่ $A$ เท่าเดิม จึงควรทำให้ mask เรียบก่อนจะเชื่อค่านี้

- **Aspect ratio (อัตราส่วนด้าน) และ extent (สัดส่วนพื้นที่ที่ถูกใช้)** คำนวณจากกรอบสี่เหลี่ยมที่ขนานกับแกน ซึ่งได้จาก `x, y, w, h = cv2.boundingRect(c)`

$$
\text{aspect} = \frac{w}{h}
\qquad
\text{extent} = \frac{A}{w h}
$$

เมื่อ $w$ คือ ความกว้างของกรอบ และ $h$ คือ ความสูงของกรอบ

  ค่า extent ประมาณ 1 สำหรับสี่เหลี่ยมที่วางขนานกับแกน ประมาณ 0.785 สำหรับวงกลม และประมาณ 0.5 สำหรับสามเหลี่ยม ทั้งสองค่านี้ *แปรตามการหมุน* เช่น สี่เหลี่ยมจัตุรัสที่หมุนไป 45 องศาจะได้ extent เท่ากับ 0.5 ซึ่งแยกจากสามเหลี่ยมไม่ออก วิธีแก้คือใช้ `cv2.minAreaRect(c)` ซึ่งให้กรอบที่หมุนตามรูปได้ และค่า extent เทียบกับพื้นที่ของกรอบนั้นจะได้ประมาณ 1 สำหรับสี่เหลี่ยมไม่ว่าจะหมุนไปกี่องศา

- **Solidity (ความตัน)** คือ พื้นที่ของรูปหารด้วยพื้นที่ของเปลือกนูน (convex hull — รูปนูนที่เล็กที่สุดที่ครอบรูปนั้นได้ทั้งหมด เหมือนเอายางรัดรอบวัตถุ) คำนวณพื้นที่เปลือกนูนด้วย `cv2.contourArea(cv2.convexHull(c))`

$$
\text{solidity} = \frac{A}{A_{\text{hull}}}
$$

เมื่อ $A_{\text{hull}}$ คือ พื้นที่ของเปลือกนูน

  รูปนูนทุกชนิด ซึ่งรวมถึงรูปทั้งสามแบบในโจทย์ task 6 ให้ค่าประมาณ 1 ดังนั้นค่านี้แยกรูปนูนออกจากรูปเว้าได้ ในโจทย์ task 6 จึงใช้แยกประเภทรูปไม่ได้เลย แต่มีค่ามากสำหรับการจับว่ารูปสองรูปติดกันจนกลายเป็นรูปเดียว และมีค่ามากสำหรับงานตัวอักษร

- **Image moments (โมเมนต์ของภาพ)** คือ ผลรวมถ่วงน้ำหนักของพิกัดทุกจุดในรูป ซึ่งใช้สรุปการกระจายตัวของรูปร่าง คำสั่ง `M = cv2.moments(c)` ให้โมเมนต์ดิบ

$$
M_{pq} = \sum_{x} \sum_{y} x^p y^q
$$

เมื่อ $M_{pq}$ คือ โมเมนต์ดิบลำดับ $(p, q)$ และ $x$, $y$ คือ พิกัดของจุดในรูป

  ดังนั้นพื้นที่คือ $M_{00}$ และจุดศูนย์ถ่วงคือ $(M_{10}/M_{00},\, M_{01}/M_{00})$ ถ้าลบจุดศูนย์ถ่วงออกจากทุกพิกัดก่อน จะได้โมเมนต์กลาง $\mu_{pq}$ ซึ่งไม่แปรตามการเลื่อนตำแหน่ง และถ้าหารด้วยกำลังของ $M_{00}$ ต่อไปอีก จะได้โมเมนต์กลางแบบปรับมาตรฐาน $\nu_{pq}$ ซึ่งเพิ่มความไม่แปรตามการย่อขยายเข้ามาด้วย

- **Hu moments ทั้ง 7 ตัว** คือ การนำ $\nu_{pq}$ มารวมกันเป็นตัวเลข 7 ค่า ที่เพิ่มความไม่แปรตาม **การหมุน** เข้ามาอีกชั้นหนึ่ง คำสั่งคือ `cv2.HuMoments(M)` สรุปบันไดความไม่แปรได้ว่า โมเมนต์ดิบไม่มีความไม่แปรอะไรเลย โมเมนต์กลางเพิ่มความไม่แปรตามการเลื่อน โมเมนต์กลางแบบปรับมาตรฐานเพิ่มความไม่แปรตามการย่อขยาย และ Hu เพิ่มความไม่แปรตามการหมุน นอกจากนี้ตัวที่ 7 ยังเปลี่ยนเครื่องหมายเมื่อภาพถูกพลิกกลับด้าน จึงใช้ตรวจการสะท้อนกระจกได้ ค่าเหล่านี้กินช่วงตัวเลขกว้างมากหลายระดับ จึงต้องเทียบกันในรูป $\operatorname{sign}(h) \log_{10} \lvert h \rvert$ เสมอ

ตัวอย่างที่ใช้จริง การแยกรูปทั้งหมดของโจทย์ task 6 ใช้ตัวเลขเพียงสองตัว กำหนด `v = len(approxPolyDP(c, 0.02 * P, True))` และ $\text{circ} = 4\pi A / P^2$ จากนั้น `v == 3` คือสามเหลี่ยม `v == 4` คือสี่เหลี่ยม และ `circ > 0.8` คือวงกลม ส่วนอะไรที่เหลือจากนั้นคือความบกพร่องของ mask ไม่ใช่รูปร่างแบบที่สี่

## [problem-first] เริ่มจากโจทย์จริง แล้วหาว่าต้องรู้อะไร

เปิดไฟล์ [`task6_Simple_Objects.md`](../faio-2025/qualification/task6_Simple_Objects.md) ส่วน Tips ระบุชุดเครื่องมือนี้ตรง ๆ ว่า "shape classification using properties like **number of corners, aspect ratio, or circularity**" แปลว่าการแยกประเภทรูปร่างด้วยคุณสมบัติ เช่น จำนวนมุม อัตราส่วนด้าน หรือความกลม แต่แล้วโจทย์ก็ปลดอาวุธมันทันทีด้วยประโยคว่า "you only need to **count** the figures — not classify them by type (unless it helps your counting logic)" แปลว่าต้องแค่นับรูป ไม่ต้องแยกประเภท ยกเว้นว่ามันจะช่วยตรรกะการนับ

ต้องซื่อสัตย์กับวงเล็บนั้น ตัวเลขบรรยายรูปร่างมีที่ยืนในโจทย์ task 6 เฉพาะเมื่อตรรกะการนับต้องการมันจริง ๆ ซึ่งมีสามกรณี

1. **ใช้วินิจฉัยการเชื่อมกัน** รูปสองรูปที่แตะกันจะกลายเป็น contour เส้นเดียวที่มีค่า solidity ต่ำกว่า 1 อย่างชัดเจน ค่านั้นจึงชี้ให้เห็นก้อนที่อาจต้องนับเป็นสองรูป
2. **ใช้แยกจุดรบกวนออกจากรูปจริง** การกรองด้วยพื้นที่ขั้นต่ำอย่างเดียวจะลบวงกลมเล็ก ๆ ที่เป็นรูปจริงทิ้งไปด้วย การใช้พื้นที่ *ร่วมกับ* ความกลมจึงเป็นตัวกรองที่ปลอดภัยกว่า
3. **ใช้ตรวจสอบ mask** ถ้าตัวเลขบรรยายรูปร่างของภาพฝึกหนึ่งภาพไม่จับกลุ่มออกมาเป็นสามกลุ่มที่ชัดเจน คือ กลุ่ม v=3 กลุ่ม v=4 และกลุ่มที่ความกลมสูง แปลว่าค่าเส้นแบ่งที่ตั้งไว้ผิด และมันผิดก่อนที่การนับจะผิดเสียอีก

ทีนี้เปิดไฟล์ [`qaz_letters.md`](../faio-2025/day1/qaz_letters.md) สถานการณ์จะกลับด้านทันที โจทย์ข้อนี้ให้ชุดข้อมูลแบบตารางมาเลย โดยข้อมูลภาพของตัวอักษรคาซัค 42 ตัว "has been distilled into handcrafted numerical features" คือถูกกลั่นให้กลายเป็นคุณลักษณะเชิงตัวเลขที่คนสร้างขึ้นเองไว้แล้ว ประกอบด้วย Hu moments ซึ่งโจทย์อธิบายว่าเป็น "7 invariant moments describing shape, rotation, scale invariant" จำนวนและพื้นที่ของ contour ที่คำนวณผ่าน OpenCV ระยะทางในแนวรัศมีจากจุดศูนย์ถ่วง Fourier descriptors ของเส้นขอบ ค่าวัดความสมมาตร การฉายลงแนวนอนและแนวตั้ง การแบ่งภาพเป็นโซน $4 \times 4$ การแปลง DCT และเวฟเล็ต โดยไม่มีภาพให้เลยแม้แต่ภาพเดียว

บทเรียนนี้จึงใช้ได้สองทาง ในโจทย์ task 6 เรา *คำนวณ* ตัวเลขเหล่านี้เองและอาจทิ้งมันไปได้ ส่วนในโจทย์ `qaz_letters` ตัวเลขเหล่านี้ **คือ** ตัวชุดข้อมูล และงานของเราคืออ่านรายชื่อคอลัมน์ให้ออกว่าแต่ละตัวแยกอะไรได้และแยกอะไรไม่ได้ ผลที่คมที่สุดคือ คุณลักษณะที่ไม่แปรตามการหมุนย่อมแยกตัวอักษรที่ต่างกันเพียงทิศทางการหันไม่ได้ และคุณลักษณะที่ไม่แปรตามการย่อขยายย่อมแยกตัวอักษรที่ต่างกันเพียงขนาดไม่ได้ ดังนั้นสำหรับตัวอักษรคาซัคเก้าตัวที่ต่างกันเพียงเครื่องหมายเสริมเล็ก ๆ คุณลักษณะที่ *ไม่มี* ความไม่แปร คือการแบ่งโซนและการฉาย ต่างหากที่เป็นตัวพาข้อมูลสำคัญ

## [code-first] โค้ดที่รันได้ พร้อมคำอธิบายในคอมเมนต์

```python
import collections, cv2, numpy as np

def describe(c):
    A = cv2.contourArea(c)
    P = cv2.arcLength(c, True)
    x, y, w, h = cv2.boundingRect(c)
    hull = cv2.convexHull(c)
    # ตั้ง eps เป็นสัดส่วนของเส้นรอบรูป เพื่อให้จำนวนมุมไม่ขึ้นกับขนาดของรูป
    v = len(cv2.approxPolyDP(c, 0.02 * P, True))
    hu = cv2.HuMoments(cv2.moments(c)).ravel()
    return {
        "area": A,
        "vertices": v,
        "circularity": 4 * np.pi * A / (P * P + 1e-9),   # 1.0 วงกลม, .785 สี่เหลี่ยมจัตุรัส, .605 สามเหลี่ยม
        "aspect": w / (h + 1e-9),                        # ค่านี้แปรตามการหมุน
        "extent": A / (w * h + 1e-9),                    # เทียบกับกรอบที่ขนานกับแกน
        "extent_rot": A / (cv2.minAreaRect(c)[1][0] * cv2.minAreaRect(c)[1][1] + 1e-9),
        "solidity": A / (cv2.contourArea(hull) + 1e-9),  # ประมาณ 1 สำหรับรูปนูน ใช้ชี้รูปที่เชื่อมติดกัน
        # ค่า Hu กินช่วงกว้างหลายระดับ ต้องแปลงเป็นสเกลลอการิทึม ไม่อย่างนั้นโมเดลจะเห็นแต่ h[0]
        **{f"hu{i}": np.sign(v_) * np.log10(abs(v_) + 1e-30) for i, v_ in enumerate(hu)},
    }

def classify(d):
    if d["vertices"] == 3:            return "triangle"
    if d["vertices"] == 4:            return "rectangle"
    if d["circularity"] > 0.80:       return "circle"
    return "unknown"                  # ถ้าถัง unknown ไม่ว่าง แปลว่า mask ยังต้องแก้

gray = cv2.imread("blueprint.png", cv2.IMREAD_GRAYSCALE)
bg = int(np.bincount(gray.ravel()).argmax())
mask = (np.abs(gray.astype(int) - bg) > 20).astype(np.uint8) * 255
cnts, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

ds = [describe(c) for c in cnts if cv2.contourArea(c) >= 20]
print(len(ds), "figures")                           # บรรทัดนี้บรรทัดเดียวคือคำตอบของ task 6
print(collections.Counter(classify(d) for d in ds))  # ใช้ตรวจสอบเท่านั้น ถัง unknown ต้องว่าง
print("merged suspects:", sum(d["solidity"] < 0.9 for d in ds))   # ค่าที่ควรได้คือประมาณ 0
```
