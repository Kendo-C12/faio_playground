**ไฟล์คำตอบ (submission file)** คือ ไฟล์ CSV ที่ส่งเข้าระบบตรวจของการแข่งขัน ซึ่งระบบจะตรวจรูปแบบของไฟล์ก่อน แล้วจึงค่อยตรวจว่าทำนายถูกกี่ข้อ

โมเดลที่ไม่เก่งทำให้เสียคะแนนบางส่วน แต่ไฟล์ที่ผิดรูปแบบทำให้เสียคะแนนทั้งข้อ ในการสอบที่มีเวลา 4 ชั่วโมง ความเสี่ยงสองอย่างนี้ไม่เท่ากันเลย และมีเพียงอย่างเดียวที่กำจัดได้ฟรี

## [concept-first] ทฤษฎีก่อน แล้วดูตัวอย่าง

ระบบตรวจคำตอบจะตรวจห้าเรื่องต่อไปนี้ ก่อนที่จะมองคำทำนายของคุณเลยแม้แต่นิดเดียว

- **1. ชื่อไฟล์ ต้องตรงเป๊ะ** ไม่ใช่แค่ "ไฟล์ CSV ไฟล์หนึ่ง" โจทย์ task 4 และ task 5 ระบุชื่อ **`solution.csv`** ส่วน task 6 ระบุชื่อ **`submit.csv`** ทั้งที่เป็นการสอบรอบเดียวกันแต่ใช้คนละชื่อ ดังนั้นชื่อไฟล์คือข้อเท็จจริงเฉพาะของแต่ละข้อที่ต้องอ่านใหม่จากโจทย์ทุกครั้ง ไม่ใช่ความเคยชินที่ยกมาจากข้ออื่น

- **2. หัวตาราง ต้องตรงเป๊ะ** โจทย์ task 4 และ task 5 แสดงหัวตารางว่า `id,label` คือไม่มีช่องว่างหลังลูกน้ำ ไม่มีตัวพิมพ์ใหญ่ และไม่มีคอลัมน์เกิน ต้องใช้ `to_csv(index=False)` ไม่อย่างนั้นจะได้คอลัมน์แรกที่ไม่มีชื่อติดมาด้วย แล้วคอลัมน์ทุกตัวจะเลื่อนไปหนึ่งช่อง

- **3. จำนวนแถว ต้องตรงเป๊ะ** คือหนึ่งแถวต่อหนึ่งตัวอย่างทดสอบ ไม่ขาดไม่เกิน โจทย์ task 6 ระบุว่าทดสอบกับภาพ **8000** ภาพ ดังนั้นต้องมี 8000 แถว ส่วนไฟล์ [`faio-2025/day2/Lost_in_the_Museum.md`](../faio-2025/day2/Lost_in_the_Museum.md) เป็นโจทย์ที่เข้มงวดที่สุดในคลังทั้งหมด เพราะระบุว่าต้องมี 20,000 แถวพอดี หนึ่งแถวต่อหนึ่งภาพ โดยห้ามซ้ำและห้ามขาด และห้ามกรอง ห้ามเรียงใหม่ ห้ามข้ามแถวใด ๆ

- **4. ลำดับแถว ต้องแน่นอน** ทั้ง task 5 และ task 6 เขียนไว้ตรงกันว่าลำดับของค่า `id` ต้องเรียงตามลำดับใน `test.csv` โดยเริ่มจาก `0` ไปจนถึงค่า id สูงสุด ดังนั้นลำดับไม่ใช่สิ่งที่เลือกเองได้ ให้หาลำดับจากไฟล์ทดสอบเสมอ ห้ามเอาลำดับจาก dict, set หรือผลของ `groupby` ที่ยังไม่ได้เรียง

- **5. การสะกดคำตอบ ต้องตรงเป๊ะ** คำตอบของ task 4 คือข้อความสามแบบ ได้แก่ `ru`, `kaz` และ `eng` ไม่ใช่ `kz` ไม่ใช่ `kaz ` ที่มีช่องว่างต่อท้าย ไม่ใช่ `Kazakh` และไม่ใช่ตัวเลขที่ `LabelEncoder` (เครื่องมือแปลงข้อความเป็นตัวเลข) สร้างขึ้น ส่วนคำตอบของ task 5 คือจำนวนเต็ม `0` และ `1` ไม่ใช่ `0.0`/`1.0` และไม่ใช่ `False`/`True`

ตัวอย่างที่แสดงความไม่สมมาตรของต้นทุน สมมติว่า task 5 มีคะแนนเท่ากับข้ออื่น และโมเดลของคุณทำนายถูก 0.88 ถ้าส่งไฟล์ชื่อ `prediction.csv` แทนที่จะเป็น `solution.csv` คะแนนจะเป็น 0 แต่ถ้าส่งโมเดลที่ทำนายถูกเพียง 0.72 ในไฟล์ `solution.csv` ที่ถูกต้อง จะได้คะแนนเกือบเต็มของข้อนั้น ห้านาทีที่ใช้ตรวจสอบตามวิธีด้านล่างจึงเป็นห้านาทีที่คุ้มค่าที่สุดของการสอบทั้งรอบ

## [problem-first] เริ่มจากโจทย์จริง แล้วหาว่าต้องรู้อะไร

เปิดไฟล์ [`task6_Simple_Objects.md`](../faio-2025/qualification/task6_Simple_Objects.md) แล้วอ่านหัวข้อ Output อย่างละเอียด โจทย์ขอไฟล์ CSV ชื่อ `submit.csv` ที่แต่ละแถวมีจำนวนเต็มเพียงตัวเดียว แต่หลังจากนั้นกลับบอกว่าลำดับของค่า **`id`** ต้องเรียงตาม `test.csv` ทั้งที่ไฟล์ซึ่งมีแต่จำนวนเต็มตัวเดียวต่อแถวย่อมไม่มีคอลัมน์ `id` อยู่เลย ข้อความของโจทย์จึงขัดแย้งกันเอง

นี่คือทักษะจริงที่ต้องมี ข้อความของโจทย์คือข้อกำหนดเพียงอย่างเดียวที่ได้รับ และมันไม่สมบูรณ์ สิ่งที่ควรทำมีสี่ข้อ

1. **ดาวน์โหลดไฟล์คำตอบตัวอย่างที่โจทย์แนบมา แล้วทำตามรูปแบบของมัน** โจทย์ task 6 แนบไฟล์ `submit.csv` มาให้ด้วยเหตุผลนี้โดยตรง ไฟล์ `qaz_letters.md` แนบ `sample_submission.csv` มาให้ และโจทย์ Lost in the Museum ก็แนบมาเช่นกัน ไฟล์ตัวอย่างจะตอบทุกข้อสงสัยที่ข้อความทิ้งไว้ ทั้งชื่อคอลัมน์ การมีหรือไม่มีหัวตาราง และลำดับของแถว
2. **เมื่อมีไฟล์ตัวอย่าง ให้เชื่อไฟล์ตัวอย่างมากกว่าข้อความ** ส่วนกรณีที่ไม่มีไฟล์ตัวอย่าง ซึ่งได้แก่ task 4 และ task 5 ให้ทำตามข้อความอย่างตรงตัว และคัดลอกหัวตารางจากกรอบโค้ดในโจทย์มาทีละตัวอักษร
3. **ตรวจจำนวนแถวกับไฟล์ทดสอบ ไม่ใช่กับตารางกลางทางของตัวเอง** สำหรับ task 4 ใช้ `len(submission) == len(pd.read_csv("test.csv"))` ส่วน task 5 ใช้ `== X_test.id.nunique()` เพราะข้อนี้หลายแถวจะถูกยุบให้เหลือหนึ่ง id
4. **ให้คอลัมน์ id มาจากไฟล์ทดสอบ** สำหรับ task 5 คำสั่ง `sorted(X_test["id"].unique())` จะให้ค่า `0` ถึงค่าสูงสุดตามลำดับที่โจทย์ต้องการ และไม่มีทางทำให้ id ตัวใดหายไปเงียบ ๆ

## [code-first] โค้ดที่รันได้ พร้อมคำอธิบายในคอมเมนต์

ในโค้ดด้านล่าง ข้อความในเครื่องหมายคำพูดสามชั้นใต้บรรทัด `def` เรียกว่า docstring คือคำอธิบายสั้น ๆ ของฟังก์ชัน ซึ่งถือเป็นส่วนหนึ่งของโค้ดจึงคงไว้เป็นภาษาอังกฤษ ใจความของมันคือ ให้เขียนไฟล์ แล้วอ่านกลับขึ้นมาตรวจทันที และห้ามส่งไฟล์ที่ยังไม่ได้ตรวจเด็ดขาด

```python
import pandas as pd

def write_submission(ids, preds, path="solution.csv", n_expected=None,
                     allowed=None):
    """Write, then immediately re-read and validate. Never ship unvalidated."""
    sub = pd.DataFrame({"id": ids, "label": preds})

    # ลำดับถูกกำหนดโดยโจทย์ คือเรียง id จากน้อยไปมาก เริ่มที่ 0 จนถึงค่าสูงสุด
    sub = sub.sort_values("id").reset_index(drop=True)

    assert sub["id"].is_unique, "duplicate ids"
    assert sub["id"].iloc[0] == 0, f"ids must start at 0, got {sub['id'].iloc[0]}"
    assert sub["id"].tolist() == list(range(len(sub))), "gap in the id sequence"
    assert sub["label"].notna().all(), "NaN in label column"
    if n_expected is not None:
        assert len(sub) == n_expected, f"{len(sub)} rows, expected {n_expected}"
    if allowed is not None:                       # task 4 ใช้ {"ru","kaz","eng"}
        bad = set(sub["label"]) - set(allowed)
        assert not bad, f"illegal labels: {bad}"

    sub.to_csv(path, index=False)                 # ใส่ index=False ทุกครั้ง

    # อ่านไฟล์กลับขึ้นมาจากดิสก์ เป็นการตรวจแบบเดียวที่ตรงกับสิ่งที่ระบบตรวจจะเห็น
    back = pd.read_csv(path)
    print(open(path).readline().rstrip())         # บรรทัดหัวตารางตามที่เขียนลงไปจริง
    print(back.shape, back.dtypes.to_dict())
    return back

# task 4 — id คือลำดับแถวใน test.csv ส่วนคำตอบคือข้อความสามแบบที่ต้องสะกดตรงเป๊ะ
test = pd.read_csv("test.csv")
write_submission(range(len(test)), model.predict(test["text"]),
                 "solution.csv", n_expected=len(test),
                 allowed={"ru", "kaz", "eng"})

# task 5 — id มาจาก X_test หนึ่ง id ต่อการทำท่าหนึ่งครั้ง คำตอบเป็นจำนวนเต็ม 0 หรือ 1
Xte = pd.read_csv("X_test.csv")
ids = sorted(Xte["id"].unique())
write_submission(ids, preds.astype(int), "solution.csv", n_expected=len(ids),
                 allowed={0, 1})
```

สำหรับ task 6 รูปแบบไฟล์ต่างออกไป คือไม่มีหัวตาราง และมีจำนวนเต็มหนึ่งตัวต่อหนึ่งบรรทัด จึงเขียนด้วย `pd.DataFrame({"n": counts}).to_csv("submit.csv", index=False, header=False)` แต่ต้องตรวจเทียบกับไฟล์ตัวอย่าง `submit.csv` ที่โจทย์แนบมาก่อนเสมอ
