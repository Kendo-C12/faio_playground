**kNN (k-nearest neighbours — เพื่อนบ้านใกล้ที่สุด k ตัว)** คือ วิธีทำนายที่หาข้อมูลสอนซึ่งคล้ายกับข้อมูลใหม่มากที่สุด $k$ แถว แล้วตอบตามคำตอบที่พบบ่อยที่สุดในกลุ่มนั้น

**Decision tree (ต้นไม้ตัดสินใจ)** คือ โมเดลที่เรียนรู้ลำดับคำถามแบบใช่หรือไม่ใช่ เช่น "ค่า `ax_std` มากกว่า 0.3 หรือไม่" แล้วไล่ถามไปเรื่อย ๆ จนได้คำตอบสุดท้าย

สองวิธีนี้อยู่คนละขั้วของการทำโมเดลกับข้อมูลตาราง และการรู้ว่าข้อมูลของเราเหมาะกับแบบใด คือทักษะส่วนใหญ่ของหัวข้อนี้

## [concept-first] ทฤษฎีก่อน แล้วดูตัวอย่าง

**kNN ไม่มีการสร้างโมเดลเลย** ขั้นตอนการสอนคือการเก็บข้อมูลไว้เฉย ๆ เมื่อต้องทำนาย มันจะหาข้อมูลสอนที่ใกล้ที่สุด $k$ แถว แล้วเลือกคำตอบที่พบมากที่สุด หรือหาค่าเฉลี่ยถ้าเป็นงานทำนายตัวเลข เส้นแบ่งกลุ่มที่ได้จึงเป็นรูปร่างอะไรก็ได้ตามที่ข้อมูลวาดออกมา

**Distance metric (ตัววัดระยะห่าง)** คือ สูตรที่ใช้ตัดสินว่าสองแถวใกล้กันแค่ไหน สองแบบที่ใช้บ่อยที่สุดคือแบบ Euclidean (ระยะทางเส้นตรง ตั้งด้วย `p=2`) และแบบ Manhattan (ผลรวมของผลต่างแต่ละแกน ตั้งด้วย `p=1`)

$$
d_{\text{euclid}}(a, b) = \sqrt{\sum_i (a_i - b_i)^2} \qquad d_{\text{manhattan}}(a, b) = \sum_i |a_i - b_i|
$$

เมื่อ $a$ และ $b$ คือ ข้อมูลสองแถวที่นำมาเปรียบเทียบกัน และ $a_i$ คือ ค่าของคุณลักษณะตัวที่ $i$ ของแถว $a$

นอกจากนี้ยังมีระยะแบบ Minkowski ซึ่งใช้ค่า `p` อะไรก็ได้ และระยะแบบ cosine คือ $1 - \dfrac{a \cdot b}{\lVert a \rVert \, \lVert b \rVert}$ ซึ่งเหมาะเมื่อสนใจเฉพาะทิศทางไม่สนใจขนาด เช่นข้อมูลข้อความและ embeddings (การแทนข้อมูลด้วยเวกเตอร์ตัวเลข) ส่วนการตั้ง `weights="distance"` จะทำให้เพื่อนบ้านที่ใกล้กว่ามีสิทธิ์ออกเสียงมากกว่า

ค่า $k$ เป็นค่าเดียวที่ต้องปรับจริงจัง ถ้า $k = 1$ โมเดลจะท่องจำข้อมูลสอน คือได้ความผิดพลาดบนข้อมูลสอนเป็นศูนย์แต่ผลแกว่งมาก และเพื่อนบ้านที่มีป้ายผิดเพียงตัวเดียวก็เปลี่ยนคำตอบได้ ถ้า $k$ ใหญ่ผลจะเรียบขึ้นและเอนไปหากลุ่มที่มีข้อมูลมากที่สุด ให้เลือก $k$ ด้วย cross-validation (การตรวจสอบแบบไขว้ — ดูใน T07) และเลือกเลขคี่เพื่อเลี่ยงคะแนนเสมอในงานสองกลุ่ม

**kNN ต้องปรับสเกลคุณลักษณะเสมอ** เพราะการวัดระยะคือการบวกผลต่างยกกำลังสองข้ามทุกคอลัมน์ คอลัมน์ที่มีค่าหลักพันจึงกลบคอลัมน์ที่มีค่าอยู่ในช่วง 0 ถึง 1 จนหมด ในคุณลักษณะของ task 5 ค่า `wx_max` มีหน่วยองศาต่อวินาทีซึ่งอยู่ในหลักร้อย ขณะที่ `ax_mean` มีหน่วย g ซึ่งอยู่ราว 1 ถ้าไม่ปรับสเกล คอลัมน์ของเซ็นเซอร์วัดการหมุนจะเป็นตัวตัดสินเพื่อนบ้านทุกครั้งแต่เพียงผู้เดียว จึงต้องใส่ `StandardScaler` ก่อนเสมอ และต้องคำนวณค่าของมันจากข้อมูลสอนเท่านั้น

**ต้นไม้ตัดสินใจ คือ ลำดับคำถามที่เรียนรู้มาได้** ที่แต่ละจุดแยก โมเดลจะเลือกคุณลักษณะและเกณฑ์ที่ทำให้กลุ่มลูกทั้งสองฝั่ง "บริสุทธิ์" ที่สุด คำว่าบริสุทธิ์หมายถึงมีคำตอบชนิดเดียวมากที่สุด **Impurity (ค่าความไม่บริสุทธิ์)** คือ ตัวเลขที่วัดว่ากลุ่มหนึ่งปนกันแค่ไหน มีสองสูตรที่ใช้กัน โดย Gini มีค่าสูงสุด 0.5 และ entropy มีค่าสูงสุด 1 bit เมื่อมีสองกลุ่มที่ปริมาณเท่ากัน

$$
\text{Gini} = 1 - \sum_k p_k^2 \qquad \text{Entropy} = -\sum_k p_k \log_2 p_k
$$

เมื่อ $p_k$ คือ สัดส่วนของข้อมูลในกลุ่มคำตอบที่ $k$ ภายในจุดนั้น เช่นถ้าจุดหนึ่งมีคำตอบ 1 อยู่ 30 แถวและคำตอบ 0 อยู่ 10 แถว จะได้ $p_1 = 0.75$ และ $p_0 = 0.25$

การเลือกจุดแยกคือการทำให้ค่าความไม่บริสุทธิ์ลดลงมากที่สุดเมื่อถ่วงน้ำหนักด้วยขนาดของกลุ่มลูก

$$
\Delta I = I(\text{parent}) - \sum_i \frac{n_i}{n} \, I(\text{child}_i)
$$

เมื่อ $I$ คือ ค่าความไม่บริสุทธิ์, $n$ คือ จำนวนข้อมูลในจุดแม่ และ $n_i$ คือ จำนวนข้อมูลในจุดลูกที่ $i$

Gini กับ entropy แทบไม่เคยให้ต้นไม้สุดท้ายที่ต่างกัน และ Gini คำนวณถูกกว่าจึงเป็นค่าเริ่มต้น

**ความลึกคือปุ่มที่ควบคุมการจำมากเกินไป** ต้นไม้ที่ไม่ถูกจำกัดจะโตจนทุกใบมีคำตอบชนิดเดียว ทำให้ทำนายข้อมูลสอนได้ถูกทั้งหมดแต่ใช้กับข้อมูลใหม่ไม่ได้ ค่าที่สำคัญมีสามตัวคือ `max_depth` ความลึกสูงสุด, `min_samples_leaf` จำนวนข้อมูลขั้นต่ำในใบหนึ่งใบ และ `min_samples_split` จำนวนขั้นต่ำที่ยอมให้แยกต่อ ให้ปรับ `max_depth` เป็นอันดับแรก

**ต้นไม้ไม่ต้องปรับสเกล และไม่ต้องแปลงคอลัมน์ที่มีลำดับ** เพราะการแยกแต่ละครั้งคือคำถามว่า $x < t$ หรือไม่ ซึ่งการปรับสเกลแบบใดก็ตามที่ยังรักษาลำดับไว้จะไม่เปลี่ยนคำตอบของคำถามนี้เลย ข้อเท็จจริงข้อเดียวนี้อธิบายได้ว่าทำไมต้นไม้และ boosting จึงเป็นตัวเลือกเริ่มต้นสำหรับคุณลักษณะที่สร้างเอง ในขณะที่ kNN ไม่ใช่

## [problem-first] เริ่มจากโจทย์จริง แล้วหาว่าต้องรู้อะไร

เปิดไฟล์ [`task5_Can_You_Become_AI_Yoga_Instructor.md`](../faio-2025/qualification/task5_Can_You_Become_AI_Yoga_Instructor.md) โจทย์นี้มีคำตอบสองแบบ วัดผลด้วย accuracy (ความแม่นยำ — สัดส่วนของคำตอบที่ทำนายถูก) และข้อมูลกลายเป็นตารางหลังจากสรุปตาม `id` แล้ว ลักษณะเหล่านี้บังคับสี่อย่างต่อไปนี้

1. **ตัวอย่างน้อย แต่คอลัมน์ที่สร้างเองมีมาก** เพราะหนึ่งแถวคือการทำท่าหนึ่งครั้ง จึงเหลือข้อมูลไม่กี่ร้อยแถวเทียบกับคุณลักษณะหลายสิบตัว kNN ทำงานได้ไม่ดีในมิติหลายสิบมิติ เพราะระยะทางระหว่างทุกคู่มีค่าใกล้เคียงกันไปหมด ในขณะที่ต้นไม้ตื้น ๆ อ่านเข้าใจได้และเร็ว
2. **วัดด้วย accuracy กับคำตอบสองแบบที่มีจำนวนใกล้เคียงกัน** จึงไม่ต้องยุ่งกับการถ่วงน้ำหนักกลุ่ม และต้นไม้ที่จำกัดความลึกคือโมเดลพื้นฐานที่ใช้ได้จริง ฟิตเสร็จในหนึ่งวินาที และตรวจความสมเหตุสมผลได้ด้วยการพิมพ์ต้นไม้ออกมาดู
3. **หน่วยของข้อมูลต่างกัน** คือมีทั้ง g, องศาต่อวินาที และจำนวนแถว ถ้าจะลอง kNN ต้องปรับสเกลเสมอ แต่ถ้าใช้ต้นไม้ก็ข้ามคำถามเรื่องสเกลไปได้ทั้งหมด
4. **ข้อมูลมีการจัดกลุ่ม** ถ้าสร้างโมเดลจากแถวรายช่วงเวลาแทนที่จะสรุปตาม `id` ก่อน kNN จะไปเจอช่วงเวลาที่อยู่ติดกันของ **การทำท่าครั้งเดียวกัน** แล้วรายงานคะแนนที่เกือบสมบูรณ์แบบ นั่นคือข้อมูลรั่ว ไม่ใช่ความเก่ง ดูรายละเอียดใน T07

ส่วนไฟล์ [`qaz_letters.md`](../faio-2025/day1/qaz_letters.md) มี 42 กลุ่ม และคุณลักษณะถูกสร้างมาให้แล้วโดยกรรมการ ต้นไม้ต้นเดียวแบ่ง 42 กลุ่มได้ไม่ดีนัก เพราะแต่ละใบจะเห็นตัวอย่างของแต่ละตัวอักษรน้อยมาก แต่ต้นไม้เป็นหน่วยย่อยที่ T11 และ T12 นำไปประกอบกันเป็นชุดโมเดล ให้ฟิตต้นไม้หนึ่งต้นกับข้อมูลนั้นเพื่อดูว่าจุดแยกเลือกใช้คุณลักษณะตัวใด แล้วจึงค่อยขยับไปใช้ชุดโมเดล

## [code-first] โค้ดที่รันได้ พร้อมคำอธิบายในคอมเมนต์

```python
import numpy as np
import pandas as pd
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier
from sklearn.tree import DecisionTreeClassifier, export_text
from sklearn.model_selection import cross_val_score, StratifiedKFold

# X คือ หนึ่งแถวต่อหนึ่ง id (คุณลักษณะของ task 5 ที่สรุปแล้ว) ส่วน y คือ คำตอบ 0 หรือ 1
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)

# kNN ต้องวางตัวปรับสเกลไว้ข้างใน Pipeline เพื่อให้แต่ละรอบคำนวณจากแถวฝั่งสอนเท่านั้น
for k in (1, 3, 5, 9, 15, 25):
    knn = make_pipeline(StandardScaler(),
                        KNeighborsClassifier(n_neighbors=k, weights="distance"))
    s = cross_val_score(knn, X, y, cv=cv, scoring="accuracy")
    print(f"kNN k={k:2d}  {s.mean():.4f} +/- {s.std():.4f}")

# kNN ตัวเดิมแต่ไม่ใส่ตัวปรับสเกล เพื่อดูว่าการปรับสเกลมีค่าแค่ไหนกับข้อมูลชุดนี้
print("unscaled", cross_val_score(KNeighborsClassifier(5), X, y, cv=cv).mean())

# ต้นไม้ไม่ต้องใช้ตัวปรับสเกล ให้ไล่ค่าความลึก ซึ่งเป็นปุ่มควบคุมการจำมากเกินไป
for d in (2, 3, 5, 8, None):
    tree = DecisionTreeClassifier(max_depth=d, min_samples_leaf=5,
                                  criterion="gini", random_state=42)
    s = cross_val_score(tree, X, y, cv=cv, scoring="accuracy")
    print(f"tree depth={str(d):4s}  {s.mean():.4f} +/- {s.std():.4f}")

# ต้นไม้ความลึก 3 เล็กพอที่จะอ่านได้ และควรอ่านจริง เพราะมันบอกว่า
# คุณลักษณะที่สร้างเองตัวใดมีข้อมูลจริง ซึ่งเป็นข้อมูลนำเข้าของ T16 และ T12
tree = DecisionTreeClassifier(max_depth=3, random_state=42).fit(X, y)
print(export_text(tree, feature_names=list(X.columns)))
```

4. เรียกว่า overfitting คือการจำข้อมูลสอนมากเกินไป วิธีแก้คือจำกัด `max_depth` เพิ่ม `min_samples_leaf` หรือย้ายไปใช้ชุดโมเดลตาม T11 และ T12
5. เพราะช่วงเวลาที่อยู่ติดกันของการทำท่าครั้งเดียวกันมีค่าเกือบเหมือนกันทุกประการ โมเดลจึงไปหยิบ `id` เดิมจากฝั่งข้อมูลสอนมาตอบ วิธีแก้คือสรุปข้อมูลตาม `id` ก่อน หรือใช้ `GroupKFold` โดยจัดกลุ่มด้วย `id`
6. เพราะมันบอกชื่อคุณลักษณะที่จุดแยกเลือกใช้จริง ซึ่งทำให้รู้ว่าคอลัมน์ที่สร้างขึ้นเองตัวใดคุ้มค่าที่จะเก็บไว้ และตัวใดควรตัดทิ้งก่อนไปใช้โมเดลที่กินเวลามากกว่า

**แบบฝึกจากโจทย์จริง:** ใช้คุณลักษณะของ task 5 ที่สรุปแล้ว ไล่ค่า $k$ และ `max_depth` ตามโค้ดด้านบน แล้วจดคะแนน cross-validation ที่ดีที่สุดของแต่ละตระกูลโมเดลไว้ นำตัวเลขทั้งสองไปเป็นเกณฑ์พื้นฐานที่ต้องเอาชนะใน T11 และ T12

## ข้อควรระวัง และสรุปสำหรับอ่านทบทวน 60 วินาที

- kNN ต้องปรับสเกลเสมอ และต้องวางตัวปรับสเกลไว้ใน `Pipeline` เพื่อไม่ให้ cross-validation เกิดข้อมูลรั่ว
- kNN ไม่มีคะแนนบนข้อมูลสอนที่ควรอ่าน ให้เชื่อคะแนนจาก cross-validation เท่านั้น
- ใช้ $k$ เป็นเลขคี่เมื่อคำตอบมีสองแบบ และเลือก $k$ ด้วย cross-validation ไม่ใช่ด้วยข้อมูลสอน
- ต้นไม้ไม่สนใจสเกลเลย แต่สนใจ `max_depth` และ `min_samples_leaf` อย่างมาก
- ค่า Gini สูงสุดคือ 0.5 และ entropy สูงสุดคือ 1 bit เมื่อมีสองกลุ่มที่ปริมาณเท่ากัน
- ต้นไม้ต้นเดียวคือเกณฑ์พื้นฐานและเครื่องมือวินิจฉัย ไม่ใช่โมเดลสุดท้าย แต่เป็นชิ้นส่วนที่ใช้สร้าง T11 และ T12
- คุณลักษณะที่สร้างเองจำนวนมากทำให้ kNN แย่ลง เพราะระยะทางกระจุกตัวเข้าหากัน ในขณะที่ต้นไม้ไม่ได้รับผลกระทบ
