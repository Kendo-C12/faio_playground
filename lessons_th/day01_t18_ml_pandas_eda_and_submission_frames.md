## [concept-first] ทฤษฎีก่อน แล้วดูตัวอย่าง

การทำงานสี่อย่างต่อไปนี้ครอบคลุมงานเกือบทั้งหมดที่ต้องใช้จริง

- **อ่านไฟล์ (Read)** คือ การนำไฟล์ CSV เข้ามาเป็นตารางด้วยคำสั่ง `pd.read_csv(path)` ผลลัพธ์ที่ได้เรียกว่า `DataFrame` (ตารางข้อมูลของ pandas ที่มีชื่อคอลัมน์และมีดัชนีประจำแถว) หลังอ่านเสร็จให้ตรวจสี่อย่างก่อนเสมอ ได้แก่ `df.shape` ดูขนาดตาราง `df.head()` ดูข้อมูลห้าแถวแรก `df.dtypes` ดูชนิดข้อมูลของแต่ละคอลัมน์ และ `df.isna().sum()` นับค่าว่างในแต่ละคอลัมน์ สี่บรรทัดนี้ช่วยป้องกันการเสียเวลาไปกับความเข้าใจผิดได้มากที่สุด

- **จัดกลุ่มและสรุป (Group and aggregate)** คือ การยุบข้อมูลหลายแถวที่มีคีย์เดียวกันให้เหลือแถวเดียวด้วยคำสั่ง `df.groupby(key)[cols].agg([...])` โดย key คือ คอลัมน์ที่ใช้จัดกลุ่ม การเปลี่ยนรูปร่างแบบนี้จำเป็นเสมอเมื่อข้อมูลมี **หลายแถวต่อหนึ่งตัวอย่าง** ซึ่งตรงกับโจทย์ task 5 พอดี เพราะหนึ่ง `id` คือการทำท่าโยคะหนึ่งครั้งที่บันทึกไว้ที่ความถี่ 200 Hz คือ 200 ครั้งต่อวินาที

เมื่อเรียก `groupby().agg()` พร้อมรายการฟังก์ชันหลายตัว ชื่อคอลัมน์ที่ได้จะกลายเป็น **MultiIndex column** (ชื่อคอลัมน์แบบหลายชั้น เช่นเป็นคู่ `('ax', 'mean')` แทนที่จะเป็นข้อความเดียว) ต้องยุบให้เป็นชั้นเดียวทันที ไม่อย่างนั้นการเรียก `df['ax_mean']` ในภายหลังจะล้มเหลวทุกครั้ง

```python
agg.columns = ["_".join(map(str, c)) for c in agg.columns]
```

- **รวมตาราง (Merge)** คือ การเชื่อมสองตารางเข้าด้วยกันโดยใช้คีย์ ด้วยคำสั่ง `pd.merge(left, right, on="id", how="left")` ใช้เพื่อนำคำตอบจากไฟล์ `y_train.csv` มาต่อเข้ากับตารางคุณลักษณะที่สรุปไว้แล้ว การตั้ง `how="left"` จะเก็บทุกแถวของตารางซ้ายไว้ครบแม้จะหาคำตอบไม่เจอ ซึ่งทำให้มองเห็นแถวที่ขาดคำตอบ แทนที่จะถูกตัดทิ้งเงียบ ๆ

- **เขียนไฟล์ (Write)** คือ การบันทึกตารางลงไฟล์ด้วย `df.to_csv("solution.csv", index=False)` ถ้าลืมใส่ `index=False` ไฟล์ที่ได้จะมีคอลัมน์แรกที่ไม่มีชื่อเพิ่มขึ้นมาหนึ่งคอลัมน์ ซึ่งทำให้ระบบตรวจคำตอบที่เข้มงวดอ่านไฟล์ผิดทั้งไฟล์

ตัวอย่างการเปลี่ยนรูปร่างข้อมูลที่ task 5 ต้องการ มีลำดับดังนี้

```
X_train.csv           ->  one row per (id, timestep)
groupby("id").agg()   ->  one row per id, many feature columns
merge(y_train)        ->  features + label, one row per id
```

## [problem-first] เริ่มจากโจทย์จริง แล้วหาว่าต้องรู้อะไร

เปิดไฟล์ [`task5_Can_You_Become_AI_Yoga_Instructor.md`](../faio-2025/qualification/task5_Can_You_Become_AI_Yoga_Instructor.md) โจทย์ให้ไฟล์มาสามไฟล์คือ `X_train.csv`, `y_train.csv` และ `X_test.csv` และระบุว่าแต่ละ `id` คือการทำท่าหนึ่งครั้ง มีสัญญาณ `ax ay az wx wy wz` บันทึกที่ 200 Hz

จากข้อความของโจทย์ สามารถหาได้ว่าต้องใช้ความสามารถใดของ pandas บ้าง

1. โจทย์บอกว่าแต่ละ `id` คือการทำท่าหนึ่งครั้ง แต่บันทึกที่ 200 Hz ดังนั้น **จำนวนแถวย่อมมากกว่าจำนวน id** จึงต้องใช้ `groupby("id")`
2. คำตอบอยู่ในไฟล์แยกต่างหากและใช้ `id` เป็นคีย์ จึงต้องใช้ `merge` หรือใช้ `set_index("id")` กับทั้งสองตารางแล้วจับคู่กัน
3. ผลลัพธ์ที่ต้องส่งคือ `id,label` และโจทย์กำหนดว่าต้องเรียงตามลำดับใน `test.csv` โดยเริ่มจาก `0` จึงต้องควบคุมลำดับให้แน่นอน ด้วย `sorted(index)` หรือการจัดเรียงใหม่ให้ตรงกับ id ในไฟล์ทดสอบ
4. ตัวอย่างที่โจทย์แสดงไว้เองกลับเป็น **หนึ่งแถวต่อหนึ่ง id** ดังนั้นสิ่งแรกที่ต้องตรวจคือ `X_test.csv.groupby("id").size().max()` ถ้าผลออกมาเป็น 1 ก็ไม่ต้องสรุปข้อมูลเลย

ข้อสุดท้ายคือบทเรียนทั้งหมดของหัวข้อนี้ ข้อความของโจทย์กับตัวอย่างของโจทย์ขัดแย้งกันเอง และ pandas ตอบคำถามนี้ได้ด้วยโค้ดเพียงบรรทัดเดียว

## [code-first] โค้ดที่รันได้ พร้อมคำอธิบายในคอมเมนต์

```python
import pandas as pd

X = pd.read_csv("X_train.csv")
y = pd.read_csv("y_train.csv")

# 1. ดูข้อมูลก่อนเสมอ ขนาดตารางที่ไม่ตรงกันจะบอกเองว่าต้องสรุปข้อมูลหรือไม่
print(X.shape, y.shape)
print(X.groupby("id").size().describe())   # จำนวนแถวต่อหนึ่งตัวอย่าง

# 2. ยุบหลายแถวของแต่ละ id ให้เหลือแถวคุณลักษณะเพียงแถวเดียว
SIG = ["ax", "ay", "az", "wx", "wy", "wz"]
agg = X.groupby("id")[SIG].agg(["mean", "std", "min", "max"])
agg.columns = ["_".join(c) for c in agg.columns]   # ยุบชื่อคอลัมน์หลายชั้นให้เหลือชั้นเดียว ทำทุกครั้ง

# 3. ต่อคำตอบเข้ามาโดยใช้คีย์ ห้ามต่อโดยอาศัยตำแหน่งของแถว
data = agg.merge(y.set_index("id"), left_index=True, right_index=True, how="left")
print(data["label"].isna().sum(), "ids without a label")   # ค่าที่ถูกต้องคือ 0

# 4. ไฟล์คำตอบ ต้องระบุชื่อคอลัมน์ให้ชัด เรียงลำดับให้แน่นอน และไม่มีคอลัมน์ดัชนี
ids = sorted(agg.index)
pd.DataFrame({"id": ids, "label": [1] * len(ids)}).to_csv("solution.csv", index=False)
```
