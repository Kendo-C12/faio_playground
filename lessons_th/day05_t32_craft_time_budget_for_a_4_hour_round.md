## [concept-first] ทฤษฎีก่อน แล้วดูตัวอย่าง

**อ่านโจทย์ให้ครบทุกข้อก่อน** ใช้เวลา 10 นาทีแรกอ่านโจทย์ทั้งหมดให้จบ ก่อนจะลงมือทำข้อใดข้อหนึ่ง เหตุผลคือการจัดลำดับความสำคัญทำไม่ได้เลย ถ้ายังไม่รู้ว่ามีอะไรอยู่ในชุดบ้าง คะแนนที่ได้ง่ายที่สุดของรอบปี 2025 อยู่ในข้อ 1 ถึง 3 ซึ่งคนที่อ่านโจทย์ครบจะเห็นทันที ส่วนคนที่ก้มหน้าเขียนโค้ดตั้งแต่ต้นมักจะเพิ่งมาเจอตอน 15:40 ซึ่งสายเกินไปแล้ว

**ตัดสินใจจากคะแนนต่อนาที ไม่ใช่จากความยาก** รอบคัดเลือกปี 2025 ให้ข้อละ 10 คะแนนกับข้อ 1, 2 และ 3 ซึ่งทั้งสามข้อเป็นการตอบด้วยกระดาษกับปากกา

- [`task1_stats_101.md`](../faio-2025/qualification/task1_stats_101.md) ถามค่าเฉลี่ย ฐานนิยม และมัธยฐาน ของตัวเลขสิบจำนวนที่พิมพ์มาให้แล้ว
- [`task2_Probability_theory_101.md`](../faio-2025/qualification/task2_Probability_theory_101.md) ถามความน่าจะเป็น $P(\text{at least one six in three rolls}) = 1 - (5/6)^3 = 0.4213$
- [`task3_Medicine.md`](../faio-2025/qualification/task3_Medicine.md) ถามโจทย์ทฤษฎีบทเบส์ ได้ $0.01 \cdot 0.99 / (0.01 \cdot 0.99 + 0.99 \cdot 0.02) \approx 0.3333$

แต่ละข้อใช้เวลาประมาณสองนาทีถ้ามีเครื่องคิดเลข รวมแล้วได้ 30 คะแนนภายในหกนาที อัตราคะแนนต่อนาทีระดับนี้ไม่มีโจทย์สร้างโมเดลข้อใดเทียบได้เลย

**ทำให้ได้คำตอบพื้นฐานก่อน แล้วค่อยปรับปรุง** โจทย์ข้อ 4, 5 และ 6 ล้วนให้คะแนนจากเกณฑ์ที่คำนวณกับข้อมูลที่ผู้เข้าสอบมองไม่เห็น คำตอบที่ **ใช้งานได้จริงแต่คุณภาพปานกลาง** ยังได้คะแนน ส่วนขั้นตอนการทำงานที่ออกแบบมาอย่างยอดเยี่ยมแต่ไม่เคยเขียนไฟล์ CSV ออกมาเลย ได้ศูนย์คะแนน

ดังนั้นโจทย์ machine learning ทุกข้อต้องผ่านการทำแบบหยาบ ๆ ให้จบตั้งแต่ต้นจนได้ไฟล์คำตอบ ก่อนที่ข้อใดข้อหนึ่งจะได้รับการปรับปรุงรอบที่สอง วิธีหยาบ ๆ ที่ใช้ได้จริงคือ ใช้ TF-IDF ร่วมกับ logistic regression สำหรับ [`task4_Who_Speaks_What.md`](../faio-2025/qualification/task4_Who_Speaks_What.md) ใช้การสรุปข้อมูลต่อหนึ่ง `id` ร่วมกับโมเดลแบบ boosting สำหรับ [`task5_Can_You_Become_AI_Yoga_Instructor.md`](../faio-2025/qualification/task5_Can_You_Become_AI_Yoga_Instructor.md) และใช้การตัดภาพด้วยค่าความสว่างร่วมกับ `findContours` สำหรับ [`task6_Simple_Objects.md`](../faio-2025/qualification/task6_Simple_Objects.md)

**กฎที่ห้ามละเมิด** กฎข้อนี้คือ *ต้องส่งไฟล์คำตอบที่ใช้งานได้ให้ครบทุกข้อ ก่อนจะเริ่มปรับปรุงข้อใดข้อหนึ่ง*

กฎนี้ไม่ใช่ความชอบส่วนตัว แต่เป็นกฎข้อเดียวที่ยังช่วยได้เมื่อการสอบเริ่มไม่เป็นไปตามแผน เช่น ชุดข้อมูลดาวน์โหลดไม่สำเร็จ โปรแกรมหยุดทำงานกลางคัน หรือเสียเวลาไปหนึ่งชั่วโมงกับข้อผิดพลาดจุดเดียว การละเมิดกฎนี้คือสาเหตุที่ทำให้คนจบการสอบด้วยคะแนนเต็มสามข้อ และศูนย์คะแนนอีกสามข้อ

**เมื่อไรควรปล่อยข้อนั้นไป** ให้ปล่อยข้อนั้นไปในสองกรณี กรณีแรกคือมีไฟล์คำตอบที่ใช้งานได้แล้ว และยังนึกไม่ออกว่าการปรับปรุงขั้นต่อไปจะทำงานด้วยกลไกอะไร กรณีที่สองคือใช้เวลาไปแล้ว 25 นาทีโดยยังไม่มีไฟล์คำตอบที่ใช้งานได้ และบอกไม่ได้ว่าขั้นตอนถัดไปที่จะทำคืออะไรอย่างเป็นรูปธรรม

ในทั้งสองกรณี ให้เขียนคำตอบที่เดาไว้ดีที่สุดลงไปแล้วเดินหน้าต่อ สำหรับโจทย์ที่ให้นับจำนวน การทำนายด้วยค่าคงที่ใกล้มัธยฐานของข้อมูลฝึกยังได้คะแนนบางส่วน ส่วนโจทย์ที่ให้แบ่งประเภท การตอบด้วยประเภทที่พบบ่อยที่สุดก็ได้คะแนนบางส่วนเช่นกัน

**กันเวลา 20 นาทีสุดท้ายไว้** เวลาช่วงนี้ไม่ใช่เวลาสร้างโมเดล แต่เป็นเวลาตรวจสอบไฟล์ ได้แก่ จำนวนแถว ชื่อคอลัมน์ ชื่อไฟล์ ลำดับของแถว และการอัปโหลดจริง

เหตุผลที่ต้องกันเวลาไว้มากขนาดนี้คือรายละเอียดของแต่ละข้อไม่เหมือนกัน โจทย์ [`task5`](../faio-2025/qualification/task5_Can_You_Become_AI_Yoga_Instructor.md) กำหนดให้ส่งไฟล์ชื่อ `solution.csv` ที่มีคอลัมน์ `id,label` และระบุว่า "ลำดับของค่า `id` ต้องเรียงตามลำดับใน `test.csv` อย่างเคร่งครัด โดยเริ่มจาก `0`" ส่วนโจทย์ [`task6`](../faio-2025/qualification/task6_Simple_Objects.md) กำหนดให้ส่งไฟล์ชื่อ `submit.csv` ชื่อไฟล์คนละชื่อกันทั้งที่อยู่ในรอบสอบเดียวกัน นี่คือสิ่งที่ 20 นาทีสุดท้ายมีไว้เพื่อจับ

**เผื่อเวลาไว้สำหรับเรื่องที่คาดไม่ถึงหนึ่งเรื่อง** รอบคัดเลือกในโฟลเดอร์ `faio-2024/qualification` เป็นคนละรูปแบบกันโดยสิ้นเชิง คือเป็นการเขียนโปรแกรมแข่งขันบนระบบ Yandex.Contest ที่จำกัดเวลา 1 วินาทีและหน่วยความจำ 64 MB ต่อข้อ และในปี 2025 รูปแบบนั้นก็ถูกยกเลิกไปทั้งหมด

ข้อสรุปคือรูปแบบข้อสอบเปลี่ยนได้ระหว่างปี จึงควรตั้งสมมติฐานไว้ว่าจะมีโจทย์อย่างน้อยหนึ่งข้อที่ไม่เหมือนอะไรเลยในคลังข้อสอบเก่า และควรเผื่อเวลาให้มัน แทนที่จะปล่อยให้มันกินเวลาทั้งรอบ

## [code-first] โค้ดที่รันได้ พร้อมคำอธิบายในคอมเมนต์

ต่อไปนี้คือตัวจับเวลาและตัวตรวจไฟล์ ที่ควรเขียนเตรียมไว้ก่อนเริ่มสอบ แล้ววางลงในเซลล์แรกทันทีที่เริ่ม

```python
import time, os, pandas as pd
T0 = time.time()
def clock(label):                      # เรียกที่ทุกจุดตรวจสอบ เพื่อบังคับให้ตัวเองรู้เวลาจริง
    m = (time.time() - T0) / 60
    print(f"[{m:6.1f} min elapsed | {240-m:6.1f} left] {label}")

# รายการไฟล์ที่ต้องส่ง เขียนไว้ก่อนลงมือเขียนโค้ดใด ๆ หนึ่งบรรทัดต่อหนึ่งข้อ
# คัดมาจากตัวโจทย์โดยตรง: ข้อ 4 กับข้อ 5 ใช้ solution.csv ส่วนข้อ 6 ใช้ submit.csv
SPEC = {
    "task4": ("solution.csv", ["id", "label"], None),
    "task5": ("solution.csv", ["id", "label"], None),
    "task6": ("submit.csv",   None,            None),   # หนึ่งจำนวนเต็มต่อหนึ่งแถว
}

def check(task, expected_rows=None):
    name, cols, _ = SPEC[task]
    assert os.path.exists(name), f"{task}: {name} MISSING — this is a zero"
    df = pd.read_csv(name)
    if cols: assert list(df.columns) == cols, f"{task}: columns {list(df.columns)} != {cols}"
    if expected_rows: assert len(df) == expected_rows, f"{task}: {len(df)} rows != {expected_rows}"
    assert df.isna().sum().sum() == 0, f"{task}: NaNs in submission"
    print(f"{task}: OK — {len(df)} rows, {list(df.columns)}")
    return df

# เขียนคำตอบสำรองไว้ก่อน ก่อนจะสร้างโมเดลจริง คำตอบที่ใช้ได้ย่อมดีกว่าไม่มีคำตอบเสมอ
def fallback_constant(ids, value, path, cols=("id", "label")):
    pd.DataFrame({cols[0]: ids, cols[1]: value}).to_csv(path, index=False)
    print(f"fallback written to {path}: {len(ids)} rows of {value}")
```

วินัยในการใช้โค้ดชุดนี้คือ ให้รัน `fallback_constant` ที่นาทีที่ 30 สำหรับโจทย์ machine learning ทุกข้อ และให้รัน `check` ที่นาทีที่ 220 สำหรับทุกข้อพร้อมกัน

## ข้อควรระวัง และสรุปสำหรับอ่านทบทวน 60 วินาที

- ใช้ 10 นาทีแรกอ่านโจทย์ให้ครบทุกข้อ ทำแบบนี้ทุกครั้งโดยไม่มีข้อยกเว้น
- เก็บคะแนนจากข้อที่คิดด้วยกระดาษกับปากกาก่อน เพราะเป็นคะแนนต่อนาทีที่สูงที่สุดในรอบสอบ
- ส่งไฟล์คำตอบที่ใช้งานได้ให้ครบทุกข้อ *ก่อน* จะเริ่มปรับปรุงข้อใดข้อหนึ่ง
- เขียนคำตอบสำรองแบบค่าคงที่ไว้ก่อนจะสร้างโมเดลจริง
- สั่งงานที่ใช้เวลานานให้เริ่มทำงานแต่เนิ่น ๆ เพราะมันกินเวลานาฬิกา ไม่ได้กินสมาธิ
- ปล่อยข้อนั้นไป เมื่อผ่านไป 25 นาทีแล้วยังไม่มีไฟล์คำตอบที่ใช้ได้ และยังนึกขั้นตอนถัดไปไม่ออก
- 20 นาทีสุดท้ายห้ามแก้ไขอะไร ให้ตรวจชื่อไฟล์ หัวตาราง จำนวนแถว ลำดับแถว การตั้ง `index=False` และยืนยันว่าอัปโหลดสำเร็จ
- ชื่อไฟล์ของแต่ละข้อในรอบสอบเดียวกันไม่เหมือนกัน เช่น `solution.csv` กับ `submit.csv` ต้องตรวจสอบ ห้ามเดาเอาเอง
- ให้คาดไว้ว่าจะมีโจทย์หนึ่งข้อที่ไม่เหมือนอะไรเลยในคลังข้อสอบเก่า และเผื่อเวลาไว้ให้มัน
