# faio_playground

Workspace for solving and testing **FAIO** problems.

**FAIO = Fizmat AI Olympiad** — a machine learning olympiad run from Kazakhstan, international since 2025. Official site: https://faio.kz/

This repo is the place to write and run code. It is not the source of the problems: the task statements come from https://github.com/abglnv/faio-tasks and are copied here read-only.

## Layout

```
faio-2024/   qualification (Yandex.Contest 71291) + day1 (69765)
faio-2025/   qualification (Yandex.Contest 81908) + day1 + day2 (Kaggle)
docs/        problem indexes — category, format and solving notes per problem
```

`qualification/` is a **round**, not a problem type: the online selection stage held before the on-site finals (`day1`, `day2`).

## Problem indexes

- [FAIO 2024 — 16 problems](docs/faio-2024-problems.md): 8 competitive-programming, 3 math, 5 ML implementation
- [FAIO 2025 — 11 problems](docs/faio-2025-problems.md): 3 math, 8 ML implementation

Each index gives, per problem, the category, input and submission format, scoring rule, and a solving note.
